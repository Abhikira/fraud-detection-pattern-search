Purpose of the application

This application compares transaction descriptions with a configurable phrase library and records matches for review. It is an informational tool, not a financial, legal, compliance, or security advisory service.

Human review is required

Phrase matching can produce false positives and miss suspicious activity that does not contain a configured phrase. A severity label reflects the library configuration, not a verified finding. Do not block payments, accuse a person, or make another consequential decision solely because of an application result. Use independent checks and established review procedures.

Authorized use and information submitted

Use the application only for lawful purposes and with authority to process the transaction information you submit. You are responsible for reviewing uploaded CSV content, protecting sensitive data, and following applicable organizational rules. Do not use the service to upload information that you are not authorized to handle.

Accounts

Self-registration is available to Gmail and Proton addresses. Email ownership is not verified. Keep your password confidential and notify the operator if you believe your account is being misused. The configured administrator can manage account status and the shared pattern library but cannot view another user's transaction records.

Access and security

Sign-in and role checks protect application pages and APIs. The operator must still restrict network access and configure secure hosting, HTTPS, a persistent session secret, database credentials, backups, and monitoring before exposing the service publicly.
