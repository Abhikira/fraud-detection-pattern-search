Information this application handles

When you scan transactions, the application receives the account reference, amount, and description that you submit, either as pasted text or as CSV rows. It stores accepted transaction records and matching detection results in the MySQL database configured by the operator. Pattern phrases, their categories, and severity settings are also stored there.

For registered users, the database stores an email address, account role and status, and a salted password hash. Passwords are not stored as plaintext. Sign-in uses a session cookie. Registration is limited to Gmail and Proton email domains, but addresses are not verified.

How information is used

Submitted information is used to compare descriptions against the configured pattern library, display scan results, and populate the transaction and detection history. A match is a text comparison and should not be treated as a conclusion that a person or transaction is fraudulent.

Storage and retention

Records remain in the configured database until an operator removes them or applies a retention process. This application does not currently provide transaction deletion or retention controls in its interface. Contact the person or organization operating this installation to ask about database access, backups, retention, or deletion.

Access and sharing

Users can view only their own transactions and detections. The configured administrator can manage account status but cannot view another user's transaction records. The administrator can add and delete shared suspicious-language patterns. Anyone able to reach the registration page can create an account, so the operator must restrict network access and secure the application and database.

The application sends submitted data to the server hosting the installation and stores it in the configured database. The application code does not intentionally send transaction contents to an analytics or advertising service. Hosting, network, logging, and backup providers chosen by the operator may process technical or stored data under their own practices.

Your choices and questions

Do not submit data you are not authorized to process. For questions about access, correction, deletion, or this notice, contact the operator of the installation. The operator should replace this notice with organization-specific information and contact details before making the service available to others.

Changes

The operator may update this notice when the application or its data practices change. The date above indicates when this template was last reviewed; it does not identify a particular operator or jurisdiction.
